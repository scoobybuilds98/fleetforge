# QuickBooks module — pre-go-live audit (2026-09-23, S-QBO-GOLIVE-AUDIT)

**Scope:** the whole QBO integration — `lib/QuickBooksClient.php`, `lib/QboPushers/*` (54 classes), `cron/qbo_*`, `api/v1/quickbooks/**` (69 endpoints), OAuth (`app/admin/oauth/qbo/*`, `lib/OAuth/StateManager.php`), the webhook receiver, settings UI. ~40k lines.
**Question asked:** "we haven't connected it to the real account yet but very close — everything has to work perfectly."
**Method:** read the code paths end to end, checked every claim that depends on Intuit behaviour against Intuit's current docs/announcements, and checked production (read-only SELECTs) to see which risks are live.

## Production state (read-only check, 2026-09-23)

- QBO never connected on prod (all 17 map tables empty, environment still `sandbox`, sync off).
- 43 customers, all CAD. Invoices: 1,809 draft, 99 **overdue**, 153 void — 99/99 overdue and 1,805/1,809 drafts carry GST/PST.
- 6 of 1,908 invoices have a line where `amount ≠ quantity × unit_price` (e.g. mileage_usage qty 3823 × 229.38 → amount 229.38).

## Follow-up — S-QBO-BILLPAY-MIRROR (2026-09-23): bill payments made in QuickBooks
